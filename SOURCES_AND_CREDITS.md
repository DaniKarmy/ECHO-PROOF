# Sources and Credits

## PRIMARY — Krasheninnikov

- NASA Scientific Visualization Studio, **SVS 5675** — Krasheninnikov / NISAR visualization
  - https://svs.gsfc.nasa.gov/5675/
- ECHO PROOF uses frozen representative visualization frames labelled **Jun 18 2026** and **Jun 30 2026**, cropped with one fixed shared ROI.
- Scientific boundary: NASA identifies the evolving bright field in the visualization as lava. ECHO PROOF does not classify lava; it measures visual brightness density in the rendered visualization.

## METHOD TRANSFER — Night Lights

- NASA Scientific Visualization Studio, **SVS 5313** — Change in Night Lights between 2012 and 2023 (EIC reference)
  - https://svs.gsfc.nasa.gov/5313/
- NASA Scientific Visualization Studio, **SVS 5276** — annual-series provenance / Black Marble / Suomi NPP VIIRS
  - https://svs.gsfc.nasa.gov/5276/
- ECHO PROOF uses frozen 2012 and 2023 global annual-average transfer images derived deterministically from the NASA 5276 “only lights” series.
- Scientific boundary: ECHO PROOF measures visual brightness density. It does not infer population, economic activity, urban growth, physical radiance, or the cause of a lighting change.
